# Full Stack Bootstrap AI 🚀

A production-grade collection of modular engineering context structures and automation scripts designed for modern AI-assisted development workflows. 

This repository leverages the **Spec-Driven Development** methodology to transform tools like **Continue** into autonomous Senior Systems Architects and high-performance engineering mentors.

**Optimized primarily for:**
- 🧠 **AI-Guided Learning to accelerate your path to Senior Engineer**
- ⚡ **Scalable MicroSaaS Systems Architecture**
- 🏗️ **Modular Domain-Driven Backends**
- 🎨 **Premium, High-Performance Frontends**

---

## 🏗️ Core Stack Expertise

The modular structures are natively tailored around a production-ready ecosystem:
- **Frontend**: React, TailwindCSS, React Three Fiber (R3F), Vite
- **Backend**: FastAPI, Python, PostgreSQL, Redis, RabbitMQ
- **Infrastructure**: Docker, NGINX Reverse Proxy, JWT Authentication, REST APIs

## 🧩 Agent Architecture (Directory Framework)

The repository is decoupled into specialized layers containing your **5 core architecture files** to maximize token efficiency and maintain pristine contextual boundaries:

1.  **`rules/` (Global Rules)**
    *   `Backend.Rules.md`: Strict conventions for service layers, DTO validation, and infrastructure boundaries.
    *   `Frontend.Rules.md`: Scalable React patterns, state management, and rendering lifecycle awareness.
2.  **`skills/` (On-Demand Tech Catalog)**
    *   `Main.Skills.md`: Global engineering behavior, senior-level mindset guidance, and technical teaching structures.
    *   `Examples.Skills.md`: Dense production-ready codebase examples and reference patterns (such as your 64KB architecture snippet).
3.  **`mcp/` (Model Context Protocol)**
    *   `Guide.MCP.md`: Rules instructing the LLM on how and when to leverage filesystem tools and documentation scrapers.
4.  **`spec-driven/` (Product & System Design)**
    *   `I suggest that you create your SystemDesign.md`: Lean product specifications, SaaS roadmap milestones, and system boundaries.

## 🚀 Instant Installation & Usage

You no longer need to manually copy file paths. This package includes an automated CLI configuration engine.

### 1. Initialize the AI Workspace
Open your terminal in any directory and execute the global bootstrap command via `npx`:

```bash
npx @joaosens/fullstack-bootstrap-ai
```

This script will automatically detect your operating system, locate your local Continue `config.yaml` profile, and seamlessly map your architecture layers to your environment.

### 2. Interaction in your IDE
Once installed, restart your chat window. You can interact with the modules seamlessly:
- **Architecture Rules** run silently in the background (`rules`) to enforce senior-level guardrails.
- Type `@Main.Skills` or `@Example.Skills` in the prompt bar to append dense technical knowledge or structural code references into specific conversations.
- Type `@SystemDesign.Spec` (If you created your own markdown skill) to lock the agent's logic into your roadmap specifications before requesting code generation.

## 📜 Engineering Philosophy

- **AI-Guided Mentorship**: Forced pedagogical behavior. The agent will not just hand over code; it explains the *why*, compares junior vs. senior approaches, and builds autonomy.
- **Explicit over Magical**: Prioritize explicitness, clean abstraction boundaries, and production safety over toy tutorial examples.
- **Token Efficiency**: Separate background behaviors from heavy code examples to keep active contextual windows clean and fast.
