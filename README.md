# Full Stack Bootstrap AI 🚀

A production-grade collection of modular engineering context structures and reference patterns designed for modern AI-assisted development workflows. 

This repository leverages the **Spec-Driven Development** methodology to transform tools like **Continue** into autonomous Senior Systems Architects and high-performance engineering mentors.

**Optimized primarily for:**
- 🧠 **AI-Guided Learning to accelerate your path to Senior Engineer**
- ⚡ **Scalable MicroSaaS Systems Architecture**
- 🏗️ **Modular Domain-Driven Backends**
- 🎨 **Premium, High-Performance Frontends**

---

## 🏗️ Core Stack Expertise

The modular structures are natively tailored around a production-ready ecosystem:
- **Frontend**: React, TailwindCSS, React Three Fiber (R3F), Vite
- **Backend**: FastAPI, Python, PostgreSQL, Redis, RabbitMQ
- **Infrastructure**: Docker, NGINX Reverse Proxy, JWT Authentication, REST APIs

---

## 🧩 Agent Architecture (Directory Framework)

The repository is decoupled into specialized layers containing your core architecture files to maximize token efficiency and maintain pristine contextual boundaries:

1.  **`rules/` (Global Rules)**
    *   `backend-rules.md`: Strict conventions for service layers, DTO validation, and infrastructure boundaries.
    *   `frontend-rules.md`: Scalable React patterns, state management, and rendering lifecycle awareness.
2.  **`skills/` (On-Demand Tech Catalog)**
    *   `main-skill.md`: Global engineering behavior, senior-level mindset guidance, and technical teaching structures.
    *   `examples-skill.md`: Dense production-ready codebase examples and reference patterns (such as your 64KB architecture snippet).
3.  **`mcp/` (Model Context Protocol)**
    *   `guide-mcp.md`: Rules instructing the LLM on how and when to leverage filesystem tools and documentation scrapers.
4.  **`spec-driven/` (Product & System Design)**
    *   `product-spec.md`: Lean product specifications, SaaS roadmap milestones, and system boundaries.

## 🚀 Installation & Usage

This package is distributed as a global NPM dependency to ensure permanent, reliable file paths on your operating system.

### 1. Install the Package Globally
Open your terminal and pull the latest stable bundle:

```bash
npm install -g @joaosens/fullstack-bootstrap-ai@latest
```

### 2. Link Files to your Continue Configuration
Open your local Continue configurations profile (`config.yaml`) and link the files directly from your global repository folder:

```yaml
prompts:
  # RULES (Silently executed in the background)
  - uses: file://C:/Users/OEM/AppData/Roaming/npm/node_modules/@joaosens/fullstack-bootstrap-ai/rules/backend-rules.md
  - uses: file://C:/Users/OEM/AppData/Roaming/npm/node_modules/@joaosens/fullstack-bootstrap-ai/rules/frontend-rules.md
  - uses: file://C:/Users/OEM/AppData/Roaming/npm/node_modules/@joaosens/fullstack-bootstrap-ai/mcp/guide-mcp.md

  # SKILLS & SPECS (Invocable on-demand inside the chat window)
  - uses: file://C:/Users/OEM/AppData/Roaming/npm/node_modules/@joaosens/fullstack-bootstrap-ai/skills/main-skill.md
  - uses: file://C:/Users/OEM/AppData/Roaming/npm/node_modules/@joaosens/fullstack-bootstrap-ai/skills/examples-skill.md
  - uses: file://C:/Users/OEM/AppData/Roaming/npm/node_modules/@joaosens/fullstack-bootstrap-ai/spec-driven/product-spec.md
```
*(Note: If you are running on macOS or Linux, replace the path prefix with your default global directory: `file:///usr/local/lib/node_modules/...`)*

### 3. Interaction in your IDE
Restart your IDE chat interface. You can now invoke modules fluidly using the **`/` (Slash)** command menu:
- **Architecture Rules** run silently behind the scenes to enforce senior-level guardrails automatically.
- Type `/main-skill` or `/examples-skill` in the prompt bar to append dense technical insights or code structural templates into specific questions.
- Type `/product-spec` to lock the agent's logic into your business rules before requesting heavy code block generations.

## 📜 Engineering Philosophy

- **AI-Guided Mentorship**: Forced pedagogical behavior. The agent will not just hand over raw snippets; it explains the *why*, compares junior vs. senior patterns, and builds technical autonomy.
- **Explicit over Magical**: Prioritize clean abstraction boundaries, explicit configurations, and production safety over toy tutorial scripts.
- **Token Efficiency**: Separate silent system constraints from dense technical knowledge bases to keep active workspace context screens fast and clean.
